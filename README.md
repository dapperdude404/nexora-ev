# NEXORA EV
Independent Android preview for Ola S1 Pro Gen 3, 4 kWh. Manual estimates only; no live telemetry or verified MoveOS compatibility. Parked use only. No firmware modifications or vehicle control.

Build with JDK 17, SDK 35 and Gradle 8.9: `gradle assembleDebug`. GitHub Actions builds a debug APK. Test on phone first.
