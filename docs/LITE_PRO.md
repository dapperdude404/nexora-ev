# Lite Pro architecture
Target: Ola S1 Pro Gen 3, 4 kWh; user-reported 3 GB RAM. Compatibility unverified.
Use native Views, no persistent service by default, no network permission, bounded local storage, optional offline inference. Targets: APK <10 MB, active PSS <80 MB, cold start <2 s; measure on phone and authorized parked dashboard. Static APK analysis only for documented interfaces; no root, security bypass, CAN writes or firmware changes.
